# Этап 5 — кабинеты и «Смотреть как»

Проверено 5–6 ноября 2026 года. Канонический проект: `D:\www\arena`.
Работа выполнена локально, в изолированной тестовой базе, без публикации.

## 1. Что сделано и почему

### Три кабинета

- **`/student`**: продолжение последнего занятия, возврат в незавершённую самостоятельную попытку, повторение по сохранённой истории, задания учителя со сроками и статусами, закладки и выбранные курсы. Темы показывают «не пробовал», «пробовал», «разобрал с помощью», «решил сам на новом варианте» или «пора повторить». Прочитанный конспект и самооценка не считаются независимым решением. Истёкшее время отображается отдельно от сохранённого состояния попытки.
- **`/teacher`**: собственные классы, очередь ручной проверки, переход к прогрессу класса по темам и просмотру конкретного ученика. Из темы можно выбрать задачи и назначить работу через существующий механизм Work / WorkVersion. Прежний набор задач в корзине при этом не заменяется. На собственной работе есть пробное решение через Preview as student.
- **`/admin`**: сохранены пользователи, назначение ролей учителя, доступ и импорты. Добавлены обзор записанных источников и категорий версий, журнал последних событий аудита, View as teacher / View as student и отдельные кнопки просмотра пользователя только для чтения. Обзор не переименовывает источники и не выполняет классификацию Этапа 6.

### Два отдельных режима линзы

**Предпросмотр роли (`ROLE`)** использует настоящий ID владельца сессии с более узкой ролью. Учитель может выбрать ученика, администратор — учителя или ученика. Вход под чужой учётной записью не выполняется. Пробные ответы хранятся только в памяти страницы: не создаются Attempt, Answer, Review, IndependentCheck, PracticeStudy, LearningProgress или UsageEvent. Полная проверка Quadratics использует прежний проверяющий механизм; предпросмотр назначенной работы — существующий `automaticPoints`. Письменное рассуждение не получает автоматическую оценку.

**Просмотр пользователя (`USER`)** показывает выбранный аккаунт только для чтения. Учитель может выбрать активного ученика своего активного класса; администратор — конкретного учителя или ученика. Администратор не может быть целью. Для учителя дополнительно ограничены задания, ответы и файлы: его собственные работы и завершённая самостоятельная практика, доступная ему как наставнику. Чужое задание того же ученика, его файлы и незавершённая независимая практика не становятся доступными через смену ID.

### Защита

- Состояние находится в настоящей серверной Session: режим, роль, ID цели, время активности и случайный идентификатор поколения. Клиент не назначает себе права.
- В Session добавлены пять nullable-колонок одной аддитивной миграцией. `Session.userId` остаётся настоящим пользователем; чужие пароли и токены не выдаются.
- Общий обработчик API запрещает записи в USER и допускает в ROLE только операции проверки/помощи без сохранения. Это работает и для прямого запроса в обход интерфейса.
- Идентификатор поколения в заголовке проверяет актуальность запроса. Запрос старой вкладки после смены режима или истечения времени не выполняется от настоящего аккаунта.
- При каждом запросе повторно проверяются роль и доступ к цели. Отзыв членства в классе прекращает доступ.
- Вход и выход записываются в AuditEvent с настоящим пользователем, режимом, целью и временем. Сброс по бездействию или отзыву доступа также записывается.
- После 30 минут без зарегистрированной активности линза сбрасывается; выход из аккаунта очищает её и отзывает настоящую сессию. Обычные запросы чтения не продлевают срок. Интерфейс передаёт активность клавиатуры, указателя и прокрутки, с ограничением частоты.
- На страницах видна полоса `You are viewing as … · Exit`, включая страницы, где обычная шапка скрывается.
- Заблокированы формы, изменение курсов, корзины и настроек. Черновики, результаты, самооценка и фильтры линзы не записываются в обычное хранилище браузера. Язык просматриваемого ученика не перезаписывает cookie и localStorage учителя.
- Чтение истёкшей попытки в линзе не вызывает её автоматическое завершение или оценивание.

Перед началом принятие Этапа 4b зафиксировано отдельным локальным коммитом `3d950d51c16dce18628f97650dc89fa1c2c4a355`, только с файлами его отчёта. Изменения Этапа 5 оставлены для проверки, без коммита.

## 5. Ограничения и что не сделано

- **Этап 6 не начат.** Источники не переклассифицировались, новые версии учебных текстов не выпускались, старый банк не скрывался.
- Статус самостоятельного решения на новом варианте требует подтверждённого семейства вариантов в истории Quadratics. Для материала без таких доказательств не выставляется выдуманное освоение.
- В очереди учителя показаны первые 20 работ; остальные доступны в результатах назначенных работ. В аудите — последние 50 событий. Подборка из темы показывает первые 50 доступных задач; для другой подборки остаётся общий каталог.
- Учитель не получает доступ к чужим заданиям своего ученика, личным загрузкам вне разрешённой работы и незавершённой независимой практике. Для просмотра администратора отдельного режима не добавлено.
- Ручные решения требуют самостоятельного разбора или проверки учителем; предпросмотр не имитирует ИИ-проверку и не превращает самооценку в официальные баллы.
- Производительность измерена локально, без ограничения CPU/сети. Это лабораторные образцы взаимодействий, не полевой INP, Lighthouse или проверка Hostinger.
- При быстрых переходах headless-браузера Next.js иногда пишет прежнее `The destination stream closed early`, digest `328360726`. В завершённой матрице нет ошибок JavaScript или HTTP 5xx. Зависимости и обработчики ошибок ради подавления сообщения не менялись.
- Синтетические QA-данные и файлы доступа остаются в игнорируемой `.local/` и изолированной базе. Пароли, токены и строки подключения в отчёт и исходные файлы не вынесены.
- Этап 5 не закоммичен. Для проверки оставлен локальный сервер `http://127.0.0.1:3102`; личные кабинеты требуют соответствующего локального аккаунта.

Вопросов, мешающих завершению Этапа 5, нет. После отчёта работа останавливается.
