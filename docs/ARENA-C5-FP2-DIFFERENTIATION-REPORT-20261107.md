для логарифмической замены сохраняется переменная u. Использован прежний
ограниченный точный алгебраический парсер; произвольная эквивалентность
трансцендентных выражений не объявляется реализованной. Есть свежие варианты,
гостевые черновики и повторение после ошибки.
