### Запрет до проверки

Сервер допускает для не-администратора только неархивную задачу, разрешённую прежними правилами доступа, если это ORIGINAL либо явно одобренный владельцем материал. UNKNOWN скрыт даже при originManual=true. Проверены каталог, поиск, курсы/темы, старый library API, практика, повторение, создание работ, корзина, история, preview/ROLE/USER и файлы/подписанные grants. В архивной или непроверенной истории сохраняются собственный ответ и полученный балл с заглушкой вместо условия.

В общем writer TaskVersion включён классификатор: новый Cambridge сразу архивируется, другой новый импорт остаётся UNKNOWN. Его вызывают admin/bank/*, обычный importer, pilot-import и авторские импортёры. При повторном неизменённом импорте прежний одобренный ORIGINAL не теряется; UNKNOWN не получает одобрение автоматически. Ручная отметка защищена блокировкой Task в транзакции и не перезаписывается. Для новой содержательной редакции без ручной отметки снова требуется проверка. Текстовая миграция 6b не сбрасывает проверенное происхождение.

В административном архиве доступны классификация одной задачи и всей применённой партии импорта. Для партии сначала формируется dry-run с fingerprint, затем проверяются прежние значения каждой строки под блокировкой. Запись создаёт приватный журнал и AuditEvent. Старый архив не снимается автоматически при смене класса. Проверены отказ учителю, отказ устаревшему fingerprint и точное обратное восстановление политики.

### Dry-run, журнал и восстановление

Основной скрипт scripts/content-stage6b.ts работает только с loopback test-базой maths4u_test_bank_*. Без --apply он ничего не меняет. Для записи нужны действующий локальный администратор и новый уникальный путь --journal. До транзакции журнал получает прежние/новые отметки, предопределённые новые Version ID, прежние/новые contentHash и отпечаток базы. В нём нет паролей или строки подключения. Повторный запуск не затирает файл.

Выполнен цикл: применение → проверка всех 516 задач/50 конспектов → восстановление → сверка всех исходных строк → итоговое применение и повторное сравнение. **Задачи и версии не удалялись.** Откат текстов создаёт обратные версии с прежним содержанием, а не стирает историю. Поэтому после проверенного цикла общее число TaskVersion: **3 404 → 4 952**, LessonVersion: **266 → 416**. Это 516 + 516 + 516 новых версий задач и 50 + 50 + 50 версий уроков за тестовый цикл и итоговое применение; актуальными являются последние чистые версии.

Текущий журнал: **.local/stage6b-20261106/final.json**. Проверенный восстановленный цикл: cycle.json. Для просмотра обратного плана:

При более поздней ручной правке, изменении текущей версии, базы или import hash скрипт отказывается перетирать решение. Скрипт для журналов партий — scripts/restore-content-batch.ts, он также поддерживает dry-run и работает только локально.
