# Презентации для урока

Учитель или администратор открывает **Курсы → курс → глава → тема → Презентации темы**.
Кнопка **Добавить ссылку** сохраняет название и ссылку Google Slides / Google Drive.
Поддерживаются обычные ссылки «Поделиться», ссылки опубликованных Slides и ссылки
на отдельные файлы Drive (в том числе PPTX/PDF, которые Google умеет показывать).
Папки, HTML-код iframe и ссылки на другие сайты не принимаются.

Материалы доступны всем учителям и администраторам Arena. Студенты и гости
не получают ссылки ни в каталоге, ни через API. Изменять, перемещать и убирать
ссылку может её автор или администратор. Удаление убирает привязку из темы;
оригинал Google не меняется. На тему можно прикрепить до 50 презентаций.
Кнопки ↑/↓ сохраняют порядок. Повторное добавление того же Google file ID
в ту же тему отклоняется, в том числе при одновременных запросах.
Опубликованная копия Slides имеет другой ID и считается отдельным материалом.

## Показ на доске

**На доску** открывает отдельный экран без навигации и списка задач:

- **Полный экран** использует браузерный Fullscreen API; при отказе остаётся
  просмотр на всё окно, доступны F11 и открытие Google в отдельной вкладке.
- **Убрать панель / Панель урока** освобождает место под слайды.
- **Скрыть экран / Показать экран** временно закрывает презентацию, не удаляя
  встроенный просмотр и его состояние.
- Список и стрелки панели переключают **презентации темы**. Слайды переключаются
  встроенными элементами Google; Arena не пытается управлять чужим iframe.
- **Google ↗** открывает показ в новой вкладке; **К теме** возвращает к задачам.
- Escape возвращает панель и раскрывает экран, когда фокус находится в Arena.
  Когда фокус внутри Google, клавиши обрабатывает Google; экранные кнопки доступны.

Arena не меняет права Google-файла. До урока нужно проверить доступ именно на
компьютере доски. Можно разрешить просмотр Google-аккаунту доски или использовать
«Все, у кого есть ссылка», если такой доступ подходит материалу. Если Google
запрашивает вход внутри iframe, используйте **Google ↗**. Для общедоступных Slides
поддерживается «Файл → Поделиться → Опубликовать в интернете».

Документация Google:
[публикация и встраивание](https://support.google.com/docs/answer/183965),
[ключи доступа resourcekey](https://developers.google.com/workspace/drive/api/guides/resource-keys).
Ключ resourcekey сохраняется в нормализованной ссылке. Сервер не скачивает файлы
Google и не получает Google-пароли или токены.

## Развёртывание и проверка

Добавлена только таблица `LessonPresentation` миграцией
`202609200001_lesson_presentations`. Существующие пользователи, задачи, назначения,
попытки, оценки и связи импорта не изменяются. Презентации не входят в пакет импорта
0606/9231: повторный импорт курсов не должен удалять добавленные учителем ссылки.

Запуск Hostinger остаётся прежним: Node.js 22, `npm run build`, `dist/server.js`.
Существующий runtime применяет миграции перед открытием рабочих API. Новые
переменные окружения и зависимости не нужны; сборка не обращается к рабочей базе.
Нельзя использовать reset, drop или db push.

Проверки:

```text
npx tsx --test tests/presentation-url.test.ts
npm run typecheck
npm run lint
npm run build
```

`tests/pilot-migration.test.ts` на новой изолированной БД проверяет применение
миграций поверх непустой старой схемы, повторный запуск и сохранность строк.
В него включены права презентаций, закрытые/архивные темы, авторство, конкурирующие
запросы, порядок, дубликаты, удаление привязки, CSRF и API-границы для гостя/ученика.
Локальный запуск требует `PILOT_LOCAL_TEST=1` и Arena MariaDB на 127.0.0.1:33317;
секреты берутся только из игнорируемого `.local/db-secrets.json`.

Вручную проверьте добавление, редактирование, порядок, показ, скрытие экрана,
полноэкранный режим и возврат к теме на широком и узком экране. Для окончательной
проверки Google нужен доступный реальный файл: синтетический ID проверяет интерфейс
и ошибки доступа, но не подтверждает отображение слайдов.
