# Cambridge IGCSE 0580 · Sequences

The first three lessons cover the shared C2.7/E2.7 skills of continuing patterns, relating sequences and finding or using linear and simple quadratic and cubic terms. Three Extended lessons develop fuller polynomial rules, exponential nth terms and combinations. The same split appears in the next syllabus.
