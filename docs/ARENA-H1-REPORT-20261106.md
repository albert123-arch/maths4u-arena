## 1. Что сделано и почему

Этап 6b зафиксирован в локальной `main`: **`5a9444aa`** — см. точный полный SHA ниже. Коммит содержит ровно **44 файла** из его отчёта, включая дорожную карту с решением H1. Набор проверен программно до staging и после коммита; output/, tmp/, test-results/ и .local/ не добавлялись.

Полный SHA Этапа 6b определяется командой `git rev-parse main`: ветка main в этом запуске после коммита 6b больше не изменялась. Приватный проверенный манифест — `.local/h1-20261106/stage6b-commit.json`.

После read-only `git fetch origin main` проверено: `origin/main` = **`3c37f2a9677b00e206b032210d91c99cd969e9d1`**. От него создана ветка **`hotfix/hide-cambridge`** в том же каноническом каталоге. Второй проект/worktree не создавался. Код Этапов 1–6b не переносился и не cherry-pick-ился.

Коммит кода H1: **`9235b04b0272845c700849df788d324343360b45`**. Его непосредственный родитель — `3c37f2a`. Отчёт добавлен отдельным локальным коммитом документации; для отправки используется вся ветка hotfix/hide-cambridge.

Добавлен небольшой общий серверный предикат по существующим TaskVersion.examBoard и Source.name. Материал исключается для всех, кроме администратора, если **любая сохранённая версия** имеет экзаменационное происхождение Cambridge. Проверка не опирается на MaterialCategory=EXAM: авторские exam-style остаются доступны.

Фактическое уточнение: точное имя Cambridge в пакете находит **2 555** задач. Ещё **99** записаны как **Cambridge International**. Включены оба точных имени в обоих полях; поиска по произвольному вхождению слова Cambridge нет. Это даёт нужные **2 654** задачи и не задевает авторские упоминания Cambridge в sourceReference/пояснениях.

Закрыты выдачи каталога и facets, `/api/catalog`, legacy library, поиск/главная, курсы/главы/темы и выбор курсов, практика и её возобновление, корзина, назначение работ, редактор/экспорт задач, старые работы и попытки, файлы/сканы всех вариантов. Проверка файла выполняется до разрешений владельца файла или работы. Учитель, владеющий Cambridge-задачей, её файлом и работой, также не получает материал. Курсы и главы без доступных задач исключены; API скрытых курсов/тем возвращает 404. Администратор сохраняет прежний доступ, включая выбор курсов.

Схема, миграции, зависимости, CSS, компоненты интерфейса и математические тексты не менялись. Sitemap этой версии содержит только `/`, `/courses`, `/library`; в нём нет адресов Cambridge-задач или курсов, менять его не потребовалось.

Это немедленное ограничение чтения, а не перенос записей в новый архив. Новые поля origin/examArchivedAt, режимы просмотра, новая главная, очистка текстов и остальные изменения полного релиза сюда не включены.

## 5. Команды владельцу и ограничения

### Отправка H1 в main на GitHub

**Эти команды здесь не выполнялись. Последний push запустит автоматический деплой Hostinger из main. Локальную main с Этапами 1–6b сейчас не отправлять.**

PowerShell, в обычном локальном терминале:

```powershell
Set-Location 'D:\www\arena'
git switch hotfix/hide-cambridge
if ($LASTEXITCODE -ne 0) { throw 'Не удалось выбрать ветку H1' }
git diff --quiet
if ($LASTEXITCODE -ne 0) { throw 'Есть незакоммиченные изменения отслеживаемых файлов' }
git diff --cached --quiet
if ($LASTEXITCODE -ne 0) { throw 'В индексе есть другие изменения' }
git fetch origin main
if ($LASTEXITCODE -ne 0) { throw 'Не удалось проверить origin/main' }
git merge-base --is-ancestor origin/main hotfix/hide-cambridge
if ($LASTEXITCODE -ne 0) { throw 'origin/main изменился: остановитесь, не используйте force' }
git log --oneline origin/main..hotfix/hide-cambridge
git push origin hotfix/hide-cambridge:main
```

Без `--force`. Если main обновился после проверки, обычный push безопасно отклонит несовместимую историю. Untracked output/tmp не добавлять и не удалять. Успех push ещё не означает завершённый деплой: дождитесь успешной сборки и запуска именно H1 в Hostinger.

### Проверки после завершения деплоя

В PowerShell без cookie — гостевой запрос:

```powershell
Invoke-RestMethod 'https://arena.maths4u.sbs/api/health'
$first = Invoke-RestMethod 'https://arena.maths4u.sbs/api/catalog?pageSize=50&page=1'
$items = @($first.items)
for ($page = 2; $page -le $first.pages; $page++) {
    $part = Invoke-RestMethod ("https://arena.maths4u.sbs/api/catalog?pageSize=50&page=$page")
    $items += @($part.items)
}
$leaks = @($items | Where-Object { $_.version.source -in @('Cambridge', 'Cambridge International') })
if ($leaks.Count -ne 0) { throw 'В гостевой выдаче остались Cambridge-задачи' }
Invoke-RestMethod 'https://arena.maths4u.sbs/api/catalog/courses' | Select-Object title, slug, count
curl.exe --silent --output NUL --write-out '%{http_code}\n' 'https://arena.maths4u.sbs/api/catalog/courses?slug=maths4u-0606'
```

- H1 закрывает всю работу/попытку, содержащую Cambridge; заглушка с собственным ответом из Этапа 6 не переносилась. Записи и оценки сохраняются для полного релиза.
