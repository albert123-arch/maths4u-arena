## 5. Ограничения

Независимая редакторская проверка преподавателем остаётся открытой.
Численная проверка рекуррентной формулы на нескольких допустимых индексах
не объявляется символическим доказательством для всех n. Границы применимости
и доказательства изложены в исходных решениях и новых конспектах; отчёт
различает численные и точные проверки. Автоматически оцениваются только
короткие ответы в объявленном формате, не развёрнутые доказательства.
