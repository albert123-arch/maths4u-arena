# Cambridge 0606 vectors

The chapter covers syllabus objectives 13.1–13.4. It starts with column vectors, signed components, addition and scalars. It then applies lengths, unit vectors and position vectors to geometry, and composes velocities to solve relative-motion and collision questions. [Cambridge syllabus 2025–2027, p. 18](https://www.cambridgeinternational.org/Images/662470-2025-2027-syllabus.pdf)
