# Cambridge IGCSE 0580 · Transformations and vectors

The four shared lessons cover C7.1. They use individual translations, horizontal and vertical reflections, rotations about the origin, a vertex or an edge midpoint, and positive scale factors including fractions. The six Extended lessons cover the rest of E7.1 and E7.2–E7.4. Both current and next syllabuses draw the same distinction.
