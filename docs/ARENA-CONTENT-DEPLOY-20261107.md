## Порядок публикации

1. Закоммитить точный manifest, отправить release/arena-d-content-20261107; дождаться Linux CI точного SHA.
2. Сохранить копию текущих файлов/приватного хранилища, подтвердить production main и резервную копию.
3. Отправить тот же проверенный SHA в main без force. Дождаться Hostinger Completed/Current. Старые Release D APPLY/BACKUP flags не включать.
4. Для каждого из 23 пакетов: dry-run, проверить create/update, apply, publish; без обновлений старых задач. Затем One Tree dry-run/apply без утверждения fallback.

6. Только после live HTTP 200 всех 23 глав публиковать PHP-ссылки на них.
