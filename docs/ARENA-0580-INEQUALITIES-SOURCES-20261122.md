# Cambridge IGCSE 0580 · Inequalities

The two Core lessons cover C2.6 representation and interpretation on a number line. The four Extended lessons add E2.6 linear inequalities, chains, two-variable graphs and listing the inequalities for a region. The Cambridge convention uses open and filled circles at strict and inclusive endpoints, broken and solid boundary lines, and shading of unwanted half-planes unless directed otherwise. Linear programming is outside E2.6. ## Answers, drawings and checks

The six lessons have 18 sections, 36 worked examples, 36 in-lesson checks, 36 extra checks and six print sheets. The task bank provides 30 short questions with 30 fresh variants, 30 written questions and 90 written variants. One-variable free-entry checks accept equivalent inequalities, joined conditions or intervals through Arena's exact checker. The two-variable checks use point tests and selected complete conditions. The written set includes blank diagrams for drawing and graphs with unlabelled boundaries for reading. Worked solutions include the drawn lines and correct shading where required. The explicitly shaded wanted-region exercise teaches the exception to the usual convention.

All 91 referenced diagrams are original SVGs. Formulas use KaTeX. Local tests passed 450 mathematical checks against the stated inequalities and lists, 132 correct and 132 incorrect field tests, 30 fresh-review routes, 120 written mark totals, and 1,808 HTML renders. All six print proofs fit a single A4 page, and their revision content fits the 390 px viewport. This is draft content.
