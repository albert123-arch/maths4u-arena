Перенесён весь обнаруженный банк этих курсов, а не выборка. Основные источники: `club-import-work/reference-data.json`, `existing-problems.json`, оригиналы изображений и публичные страницы maths4u.sbs. Сопоставлены ID всех задач, названия и порядок глав/подтем; проверены контрольные суммы 894 сохранённых страниц. Курс определяется исходными связями, не номером paper. Поэтому старые задания с paper 13 могут находиться в Further Pure 2, как в источнике.

Пакет содержит **3003 записи файлов** общим размером **383549240 байт**, включая оригинальные PNG и статические SVG. 2966 различных SHA256: одинаковые байты могут иметь разные защищённые роли и исходные ссылки. Исходные изображения не перекодируются. В источнике нет PDF для выбранного банка; существующая поддержка PDF в Arena сохранена.

Подробная ведомость: `.local/content-bank/report.json`; исходная инвентаризация: `inventory.json`. В отчёте перечислены ID всех отсутствующих материалов, количества файлов по курсам, восстановленные изображения и изменения кодирования TeX. ZIP включает эти отчёты.

- MS отсутствует у `maths4u / problems / 7352`. У остальных 2653 задач есть скан или существующий цифровой текст; наличие скана не считается оцифровкой.
- Отдельного краткого ответа нет у 169 задач FP1 и 41 задачи FP2. Решения сохранены. Ответы не извлекались путём генерации нового содержания.
- В 213 подтемах выбранных курсов не обнаружены теория, примеры, отдельные подсказки или переводы RU. Проверены EN/RU-страницы заметок. Интерфейс RU/EN сохранён, при отсутствии перевода показывается оригинал с пояснением.
- 14 задач FP1 содержат 44 структурированных подпункта с баллами/критериями: они сохранены отдельно. Остальные подпункты остаются в полном исходном HTML условия, с общей ручной оценкой и исходным максимумом. Разбивка баллов не угадывалась.
- Ранее сохранённый OCR импортирован как `OCR_UNVERIFIED`. Явные цифровые таблицы источника — `SOURCE_TEXT`, без утверждения о ручной проверке. Учитель/администратор может менять текст, статус и привязку файла к задаче или части через существующий редактор в пределах своих прав.
- Четыре URL изображений задач `8495`, `8601`, `8626`, `8630` возвращают HTTP 422. Использованы точные оригинальные question crops по метаданным источника. Невосстановленных файлов нет.
- У `6528`, `6451` локальный экспорт содержит некорректный `</html>` и дописанный хвост; импортирован полный видимый блок решения публичной страницы. У `6261` отличается только завершающий `</html>`. Исходные экспорты сохранены без изменений.
- Олимпиадный пилот: прежние 20 задач RU/EN, теория, примеры и файлы сохранены. Новая олимпиада не создаётся.

## Повторяемая подготовка локально

Нужны Node.js 22, установленные зависимости и существующая Arena-only MariaDB на `127.0.0.1:33317`. Пароль локального сервера читается из `.local/db-secrets.json`; реквизиты старых проектов не используются.

```powershell
npm run bank:capture
npm run bank:prepare
node scripts/bank/audit-source.mjs
npm run bank:verify
npm run bank:test
npm run bank:serve
```

`bank:capture` читает публичный источник и использует сохранённый кэш. `bank:prepare` также читает существующие OCR-JSON и оригиналы, на которые ссылаются метаданные, из `D:/www/maths4u/output`; новых OCR-запросов нет. Подготовка работает только с файлами, без подключения к production.

`bank:test` каждый раз создаёт **новую** базу `maths4u_test_bank_*`, применяет существующие миграции, добавляет старый пилот и контрольные пользователей/работу/ответ/оценку. Затем проверяет dry-run, полный импорт, прерывание и повтор. Старые базы не удаляет. Последний подготовленный preview использует эту отдельную базу; его настройки и случайные пароли находятся только в `.local/content-bank/runtime.json` и `preview.json`.

Каталог: `http://127.0.0.1:3103/courses`. Курс открывается по `/courses/maths4u-0606`, `/courses/maths4u-9231-fp1`, `/courses/maths4u-9231-fp2`, `/courses/maths4u-9231-mechanics`, `/courses/maths4u-9231-statistics`.

## Пакет публикации

```powershell
# Python 3 нужен только для создания и повторной проверки ZIP.
# При необходимости MATHS4U_PYTHON содержит путь к локальному python.exe.
npm run bank:package
```

Результат: `.local/content-bank/maths4u-five-courses.zip` и отдельный `.sha256`. Архив содержит папку `publish`, ведомости и эту инструкцию. Проверяются все ZIP-элементы и SHA256. Реквизитов, дампов, runtime.json и аккаунтов в архиве нет. ZIP и вся `.local` исключены из Git и `dist`.

610 пакетов: 41 пакет структуры, 38 списков файлов, 531 пакет задач. Один пакет задач содержит максимум 5 записей и 512 KiB JSON; файл — максимум 1 MiB, Base64-запрос укладывается в существующий предел API 2 MiB. Лимиты ученических PNG/JPEG/PDF остаются 8 MiB / 5 файлов на часть / 250 MiB на аккаунт. Привилегированный перенос банка использует отдельный административный путь, не ученический upload. На хранилище нужно не менее размера банка плюс 64 MiB свободного места и место для резервной копии.

## Выпуск на Hostinger

1. Перед отправкой в `main` сделать **свежие** резервные копии рабочей `u770916388_arena` и текущего `PRIVATE_STORAGE_PATH`. Проверить восстановление копии базы в отдельной тестовой базе, список/хеши приватных файлов. Ранняя копия до пилота не заменяет текущую.
2. Проверить Linux/Node.js 22 CI для точного коммита. Сохранённый workflow `Hostinger preview package` проверяет миграцию непустой MySQL 8.4, сборку без реквизитов и запуск из `hbuilds/current/nodejs/dist` с SHA256, восстановлением права исполнения engine, ранним `503` и повторным запуском. Тест Linux не равен проверке реального Hostinger.
3. После решения о выпуске объединить проверенную ветку с `main` без force push. hPanel: **Other / main / Node.js 22 / ./ / npm run build / dist / server.js**. Команда `build` по-прежнему создаёт `dist`. Windows-папку `dist` на Linux не копировать: native-зависимости собирает Hostinger из исходников.
4. Сохранить приватные настройки `MATHS4U_ENV=production`, `MATHS4U_RUN_MIGRATIONS=1`, `MATHS4U_DATABASE_NAME=u770916388_arena`, `MATHS4U_DATABASE_URL`, `APP_URL=https://arena.maths4u.sbs`, `PRIVATE_STORAGE_PATH`. Значения секретов в инструкцию не переносить. Не создавать заново администратора. Миграции `003`–`006`, если ещё не применены, и новая `202609150001_bank_materials` выполняются штатным startup. Сброса данных нет, историю миграций не обходить.
5. Проверить Runtime log, `/api/health` и вход существующего администратора. Приватное хранилище должно быть вне `hbuilds`/`public_html`; для этой установки ранее настроено `/home/u770916388/private/`, доступность и запас места проверить заново. npm через SSH не требуется.
6. Распаковать ZIP **на своём компьютере**. В `/admin/import` выбрать блок «Перенос пяти курсов 0606 / 9231» и папку `publish`. Отметить публикацию **новых** материалов, если они должны стать общедоступны. Скрытые существующие задачи/курсы остаются скрытыми.
7. Нажать **«Проверить / продолжить (dry-run)»**, скачать подробный отчёт структуры и задач. Для базы только со старым пилотом ожидаются **2618 новых задач и 36 новых версий**, без второго экземпляра пилота. Другие цифры сначала объяснить состоянием базы.
8. Нажать **«Применить проверенный импорт»**. Держать вкладку открытой: файлы → структура → задачи. При остановке/истечении сессии войти снова, выбрать ту же папку и тот же режим публикации, повторить dry-run. Не менять пакет во время выполнения. Применённые записи и файлы переиспользуются; `BANK_STALE_DRY_RUN` требует нового dry-run.
9. Повторить dry-run: **0 новых, 0 новых версий, 2654 без изменений**. Проверить 41 главу, 213 подтем, итоговые счётчики, файлы и сохранность прежних аккаунтов, опубликованных назначений, ответов и оценок по контрольным данным из резервной копии.
10. Проверить ученика и учителя, включая прямые ссылки на закрытые MS/ответы, задачу за первой сотней, телефон, вход перед практикой. Повторить деплой, сверить storage probe и хеши загруженных оригиналов. Только после этого считать хранение и выпуск проверенными на Hostinger.

Импорт не заменяет рабочую базу локальной. Соответствие — `sourceProject=maths4u`, `legacyId=problems:<id>` или `questions:<id>`. 36 числовых ID прежнего пилота связываются с прежними `Task.id`. Изменение источника создаёт новую версию; неизменившийся источник сохраняет и ручную редакцию учителя. Старые снимки работ/попытки не переписываются. После переноса повторная загрузка старого пилотного пакета блокируется, чтобы он не вернул старые версии.

## Проверки этой подготовки

- Полный локальный импорт 2654 задач и всех 3003 записей файлов; повтор, продолжение после прерывания; сравнение хешей исторических контрольных данных.
- Проверка 24067 HTML-полей реальным рендерером; отсутствие KaTeX ошибок, целостность файлов, ролей и связей. HTML/SVG не исполняют активное содержимое.
- Отдельный тест миграции непустой базы; коллизии `problems:9000`/`questions:9000`; новая версия с прежним ID; сохранение скрытого статуса, подписки и ручной правки.
- Регрессии исходного пилота, публикации пилота, проверки фотографий/PDF, каталога, самостоятельной работы, основного API; TypeScript, ESLint, `npm run build` и аудит `dist`.
- Edge: каталог, страница 6, обязательный вход, практика и помощь во всех пяти курсах, назначение учителем. Скриншоты компьютера и телефона находятся в `.local/content-bank/`.

Фактический результат Linux CI и точный SHA фиксируются отдельно в итоговом отчёте задачи. В этой подготовке новая версия, импорт, удалённое хранилище и вход на Hostinger не проверялись и не объявляются опубликованными.
