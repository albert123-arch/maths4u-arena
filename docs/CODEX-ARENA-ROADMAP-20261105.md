## 1. Цель продукта

1. Arena — будущая основная платформа. Когда она будет готова, она заменит https://maths4u.sbs.
2. На публичном maths4u.sbs после переноса должны остаться только материалы, авторство которых принадлежит Maths4U. Задачи из экзаменов Cambridge (past papers) туда не переносятся. На arena они пока остаются, ничего не удаляется (см. этап 6).
3. Позже появится проверка развёрнутых ответов с помощью ИИ. Сейчас готовится только архитектура, без реальных вызовов.
4. Три разных кабинета: ученик, учитель, администратор. Учитель может посмотреть платформу глазами ученика. Администратор может посмотреть её глазами учителя или ученика.
5. Бизнес-цель: доход от рекламы (ориентир владельца — от 1000 USD в месяц), позже — подписки (например, проверка ИИ и инструменты учителя). Доход от рекламы зависит от объёма посещений, поэтому главные двигатели проекта — полезные индексируемые страницы, быстрая загрузка и возвращаемость учеников. Реклама и подписки не должны мешать обучению: ученик пришёл решать задачи, а не кликать по баннерам.

## Этап 5. Кабинеты и режим «Смотреть как»

### 5.1. Три кабинета

- **Ученик (`/student`)**: продолжить последнее занятие; повторение по реальной истории; задания учителя со сроками и статусом; прогресс по темам честными статусами (не пробовал / пробовал / разобрал с помощью / решил сам на новом варианте / пора повторить); закладки.
- **Учитель (`/teacher`)**: мои классы; очередь «Нужно проверить»; прогресс класса по темам; быстрое создание задания из темы; кнопка «Preview as student».
- **Администратор (`/admin`)**: пользователи и роли; выдача доступа учителям; обзор контента по источникам (см. этап 6); импорты; журнал аудита; кнопки «View as teacher» и «View as student».

### 5.2. Режим просмотра («линза»)

Два разных режима, их нельзя смешивать:

1. **Предпросмотр роли** — учитель видит интерфейс ученика, администратор видит интерфейс учителя или ученика, но со своими правами и без чужих данных.
   - Учитель в предпросмотре ученика может открыть тему или своё задание и пройти его. Такие ответы не попадают в прогресс класса, статистику, очереди проверки и аналитику. Предпочтительно не сохранять их в базу вовсе; если сохранение нужно — явный флаг предпросмотра, исключённый во всех запросах, и тесты на это исключение.
2. **Просмотр конкретного пользователя** — только чтение.
   - Учитель может открыть кабинет и ответы ученика только из своих классов.
   - Администратор может открыть кабинет конкретного учителя или ученика.
   - В этом режиме запрещены любые записи: отправка ответов, оценки, изменение настроек, закладки.

Требования безопасности для обоих режимов:

- Линза хранится на сервере в сессии; клиентским параметрам не доверять.
- Эффективные права в линзе никогда не шире реальных прав пользователя. Учитель не может «посмотреть как администратор»; ученик не может включить линзу.
- Вход в линзу и выход записываются в `AuditEvent` (кто, кого или какую роль, когда). Для просмотра конкретного пользователя — обязательно.
- На всех страницах в линзе видна заметная полоса: «You are viewing as … · Exit».
- Линза сбрасывается при выходе из аккаунта и по истечении 30 минут бездействия.
- Нет входа по чужому паролю и выдачи чужой сессии.

**Тесты:** матрица ролей (ученик / учитель / администратор × режимы × чтение и запись); учитель не видит учеников чужих классов; предпросмотр не меняет прогресс и статистику; запись в режиме просмотра конкретного пользователя отклоняется на сервере.

## Этап 6. Источники контента и подготовка к переносу на maths4u.sbs

Цель: заранее знать, какие материалы можно публиковать на основном сайте, и иметь техническую возможность собрать публичную версию только из собственных материалов Maths4U. Ничего не удалять и ничего не скрывать на arena.

1. Классифицируй каждую задачу по происхождению, используя существующие поля (`Source`, `MaterialCategory`, `examBoard`, `syllabus`, `year`, `examSession`, `paper`, `questionNumber`, `sourceReference`, записи импорта):
   - `ORIGINAL` — авторские задачи Maths4U;
   - `CAMBRIDGE_EXAM` — задачи из экзаменов Cambridge;
   - `OTHER_THIRD_PARTY` — другие внешние источники;
   - `UNKNOWN` — нельзя определить автоматически.
   Если для этого нужно поле в схеме — добавь его миграцией и заполни скриптом; ручные отметки владельца не перезаписывать.
2. Подготовь отчёт: количество задач каждого класса по курсам и темам; полный список `UNKNOWN` с ID для ручной проверки владельцем; темы, где после исключения `CAMBRIDGE_EXAM` остаётся мало практики.
3. Добавь настройку окружения, например `CONTENT_PROFILE=arena | public-original` (по умолчанию `arena`). В профиле `public-original` в каталог, поиск, практику, задания, sitemap и публичные страницы попадают только `ORIGINAL`. Данные в базе остаются.

## Замечания по итогам проверки Этапа 2 (5 ноября)

- **Этап 3. Обратная связь не должна приписывать ученику ошибку, которую по ответу нельзя установить.** Пример: в вопросе «Unit coefficient» (x² − 14x + 40, правильно a = 1, h = 7, c = −9) ответ h = 5 получает «Check the sign of the centre», хотя ошибка знака дала бы h = −7.
