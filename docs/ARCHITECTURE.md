# Архитектура Maths4U

## Приложение и данные

Это тот же репозиторий Arena. Старые раздельные аккаунты и гостевые API удалены из активной сборки и сохранены в истории Git. Старые тестовые SQL и игровые аудиофайлы удалены по последующему указанию пользователя. Сохранены стек, bcrypt, QR-библиотека, компонент копирования и Node entrypoint.

Next App Router обслуживает страницы через общий адаптивный клиентский интерфейс, а `/api/[...path]` — через серверный диспетчер. Модули `src/lib`: security, classrooms, content, courses, works, olympiads, subscriptions, files, importer. Клиент переиспользует DTO через `import type`; серверные модули и секреты не входят в клиентский bundle.

Prisma — единый источник предметной модели. Начальная MySQL-миграция с внешними ключами и индексами находится в `prisma/migrations/202609130001_platform`.

- User + UserRole (несколько ролей) + Profile. Session/RecoveryToken содержат SHA-256 хеши случайных токенов.
- Classroom → ClassMembership и Work. Пользователи/классы архивируются, важные связи — `onDelete: Restrict`.
- Course → Topic → Lesson → LessonVersion → LessonText.
- Task → TaskVersion → TaskText / TaskPart / PartText / TaskOption / OptionText / AcceptedAnswer / TaskAsset. RU/EN привязаны к редакции. Source, экзаменационные метаданные и TaskTopic — отдельные поля/связи.
- Work → WorkVersion → WorkItem фиксирует конкретные задачи и максимальные баллы атомарно. API не обновляет опубликованные редакции; правка только добавляет следующую. Неизменяемость реализована сервисами, а не SQL-триггерами: прямые ручные UPDATE вне приложения запрещены эксплуатационным порядком.
- Attempt всегда содержит userId. Answer.response — валидируемый JSON `{value, optionId?}`. Answer.autoPoints, Review учителя и будущие AiSuggestion разделены.
- Olympiad → AgeGroup / Registration / Round → Work, без связи с игровыми сессиями. Схема поддерживает несколько туров и групп, UI V1 создаёт один тур и одну группу.
- Plan / Feature / PlanFeature / Subscription отделены от ролей. UsageEvent учитывает лимиты. Payment/PaymentEvent имеют уникальные внешние идентификаторы; реального обработчика платежей и начисления webhook нет.
- ImportRecord: sourceProject + legacyId и хеш нормализованного материала. AuditEvent фиксирует административные действия и проверку.

## Защита

Регистрация жёстко создаёт STUDENT. Пароли: bcrypt/12, максимум 72 байта. Cookie: HttpOnly, SameSite=Lax, Secure в production. Каждый API-запрос читает актуальную сессию, роли и статус из MySQL. Блокировка, изменение ролей и восстановление отзывают сессии.

Мутации проверяют точный Origin из APP_URL, формат и ограниченный поток тела. RateLimit находится в MySQL: восемь попыток на логин за 15 минут плюс общий лимит, отдельные лимиты регистрации, вступления и загрузок. IP-заголовки клиента не считаются доверенными.

Для объекта проверяется владелец, членство или регистрация в нужной возрастной группе. Исключённый ученик не может вернуться по старому коду без восстановления учителем. Сданные работы сохраняют доступ владельца и уполномоченного учителя после архива.

Единый server-side renderer: allowlist sanitize-html и KaTeX с trust:false и лимитами раскрытия макросов. Удаляются скрипты, обработчики событий, произвольные стили и внешние картинки. Рисунки обслуживаются через защищённый файловый API. Таблицы/длинные формулы прокручиваются внутри материала.

DTO ученика формируется по allowlist: до разрешённого момента нет solution, rubric, correct, numericAnswer, autoPoints, score, review/comment и teacherNote. Заметки учителю не выдаются ученику. При нескольких попытках решения скрыты до последней попытки или дедлайна. Олимпиаде требуются и окончание тура, и явная публикация.

## Попытки, время и проверка

Начало блокирует User в транзакции; проверка лимита и INSERT выполняются под одной блокировкой, с дополнительным составным UNIQUE. Сохранение/сдача/загрузка/проверка блокируют Attempt через параметризованный SELECT FOR UPDATE. Revision защищает от устаревшей вкладки. Повторный submit возвращает имеющуюся сдачу без изменения ответов.

expiresAt = min(дедлайн, серверный старт + лимит). Поздние ответы/файлы отвергаются, сохранённые оцениваются. Финализация выполняется при обращении к попытке, открытии результатов и перед публикацией; отдельный worker не нужен. Статус неоткрытой истёкшей попытки на панели может обновиться при следующем открытии результатов.

Автопроверка: точные допустимые строки с trim/case policy; десятичные числа с абсолютной погрешностью; один правильный вариант. Нет eval, эвристического оценивания доказательств и бонусов скорости. Ручная проверка допускает частичные баллы до максимума и комментарий.

## Файлы и подписки

PNG/JPEG/PDF проверяются по размеру, MIME, расширению и сигнатуре: 8 МБ/файл, пять файлов/часть, 250 МБ/аккаунт. Хранилище — абсолютный путь вне public; имя объекта случайное. PDF скачиваются как attachment, файловые ответы имеют no-store/nosniff/sandbox. Ученический файл нельзя превратить в публичный материал. Антивирус и object storage пока не подключены; SVG/HTML не принимаются.

Школьное ДЗ не требует подписки. Платная практика проверяет состояние, даты и возможность тарифа, учитывает лимит. История доступна после отмены/окончания. Отключение тарифа прекращает новые выдачи; старые действуют до окончания или явного отзыва.
