Пока выпускался Momentum, владелец попросил сначала предложить ускорение
мобильного `maths4u.sbs`. Выполнены только чтение кода и гостевые измерения.

Один лабораторный прогон: 390 px, CPU ×4, 150 ms latency, 1.6 Mbps,
холодный кэш. Это не Lighthouse и не полевые Core Web Vitals; INP не измерен.

|---|---:|---:|---:|---:|

| `/quadratics_bank.php?skill=completing-square` | 830 ms | 2.18 s | 0.248 | 1.16 MB |

Предлагаемый порядок, без внедрения:

1. Подмножества Inter Latin/Cyrillic с нужными символами, unicode-range,
   версионированием и нынешним font-display:swap. Сейчас файл 352 240 байт
   (344 KiB), около 57% первой загрузки главной. Русский язык сохранять.
2. Повторить трассу страницы банка, найти источник сдвигов и долгой работы,
   резервировать место под карточки/формулы, ограничить первоначальный
   объём математического рендеринга. MathJax 3 SVG уже используется;
   причинная связь с CLS одним прогоном не установлена.
3. Профилировать серверный catalogue_load: код читает весь каталог,
   агрегаты и полный content_html en/ru на каждом запросе, кэш только
   внутри запроса. Возможный отдельный кэш публичных метаданных/счётчиков
   проверить после измерения SQL. Личные страницы и прогресс не кэшировать
   общим HTML-кэшем.
4. Подключать CSS/Bootstrap-компоненты по реальному использованию,
   затем измерить эффект объединения. Девять CSS уже стартуют параллельно
   по HTTP/2, поэтому девять последовательных RTT здесь отсутствуют.
5. Для страниц с рисунками отдельно проверить размеры, lazy loading,
   производные WebP и безопасный кэш публичных неизменяемых файлов.
   Кэш закрытых решений и правила отзыва доступа требуют отдельного решения.

Brotli HTML/CSS и статический кэш на семь дней уже включены. Главная уже
не загружает MathJax. Bootstrap Icons font там не скачивается, его CSS около
11 KB. Google Analytics около 181 KB, но стартовал после LCP: уменьшение
его трафика само по себе не обещает улучшения первого экрана. SVG через img
не наследует currentColor страницы; это нужно учесть в отдельном SVG-пилоте.
Полная замена рисунков и отказ от многоязычности не являются первым этапом.

Результаты чтения/измерений: `main-performance/headers.json`,
`mobile-*.json`, `mobile-summary.json`, `findings.json` в приватной папке
выпуска. Ускорение не реализовано и ничего из него не опубликовано.
