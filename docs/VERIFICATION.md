- В тестах создаются случайные аккаунты и пароли; в базе разработки администратора по умолчанию нет.

## Критические сценарии API

- Обязательный вход; невозможность присвоить роль регистрацией, CSRF, блокировка, отзыв сессий, одноразовое восстановление и лимит входа.
- Класс и работа принадлежат учителю. Посторонние ученики/учителя не получают доступ; исключённый ученик не вступает повторно без восстановления.
- Пять одновременных start создают одну попытку. Сохранение восстанавливается; устаревшая revision не перезаписывает ответ.
- Шесть параллельных submit дают одну сдачу; дата, ответы и revision завершённой работы не меняются.
- Серверные открытие, дедлайн и лимит времени. После истечения засчитываются сохранённые ответы, новые ответы/файлы отвергаются.
- Опубликованная работа сохраняет прежние формулировки, правила и баллы после правки задачи.
- Числа, короткие строки и выбор варианта проверяются по заданным правилам; ручная проверка поддерживает частичные баллы и комментарий.
- Решения/баллы/комментарии скрываются в API до разрешения; несколько попыток не раскрывают решение после первой. Заметки учителю не выдаются ученику.
- PDF и фото приватны; неверные типы отклоняются. Ссылки на решения и ученические файлы нельзя сделать публичными через материал.
- Подписка не повышает роль; квота платной практики действует, школьное ДЗ доступно без неё, история сохраняется после отзыва.
- Уникальный внешний идентификатор PaymentEvent отвергает дубликат. Реальный webhook и начисления не подключены.
- Повторный импорт пропускает неизменённые записи, обновление добавляет редакцию, ошибочный файл не оставляет частичного импорта.
- Олимпиада: возрастная группа → регистрация → закрытый до старта тур → сдача → проверка → публикация после окончания.
- Архив сохраняет попытки, оценки и приватные файлы. Проверена очистка опасного HTML и математическое отображение.

## Браузер и мобильный экран

В production-приложении выполнен полный путь: учитель с ролью TEACHER создаёт класс; новый ученик регистрируется через UI и вступает; учитель назначает задачу; ученик вводит два ответа, дожидается автосохранения, обновляет страницу и получает оба ответа обратно; сдаёт; учитель ставит частичный балл и комментарий; публикует; ученик видит 7.5/9 и комментарий.

Экран ученика 390×844, учителя 1440×1000. Автоматически проверено отсутствие горизонтального переполнения документа, наличие KaTeX, RU/EN и теория курса. Скриншоты визуально просмотрены:

- `test-results/screenshots/mobile-attempt.png` — формула, таблица, ввод и сохранение.
- `test-results/screenshots/mobile-result.png` — итоговые и частичные баллы, комментарий.
- `test-results/screenshots/teacher-dashboard.png` — собственные класс и работа учителя.

Скриншоты и случайные тестовые данные игнорируются Git. Тестовый HTTP-сервер завершён; локальную MariaDB можно повторно использовать.

## Что не проверялось и что отложено

Деплой, настройки hPanel, удалённая MySQL/TLS, постоянство файлов на Hostinger, почта, реальные оплаты и AI не проверялись и не подключались. Массовый импорт и перенос файлов старых сайтов не выполнялись; fixtures maths4u и olymp — явно обозначенные синтетические примеры форматов.

UI первой версии поддерживает одну группу и один тур олимпиады; схема допускает расширение. Списки ограничены 100 записями. Возраст указывается пользователем. Антивирус не подключён. Неизменяемость редакций обеспечивают сервисы приложения, а не запрет прямых SQL UPDATE. Истёкшие попытки финализируются при обращении/просмотре результатов/публикации, без отдельного фонового worker.

Push, деплой и изменения действующих сайтов не выполнялись. Два старых проекта оставались доступны только для чтения.
