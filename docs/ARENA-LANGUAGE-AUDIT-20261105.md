- Проверены текущие версии `CourseText`, `TopicText`, `LessonText`, `TaskText`, `PartText`, `OptionText`; отдельно учтены предыдущие версии. Проверены метаданные текущих `TaskAsset`, связи задач с курсами/темами и происхождение импорта.

Это актуальное чтение **локальной копии**, а не заявление о текущем содержимом живого сервера. Перед внедрением на сервере карту следует сверить со свежим экспортом, если состав базы к тому времени изменится.

### План `/ru/`-адресов

Для начальной реализации предлагаются **три индексируемые пары**. Основание — имеющийся русский учебный контент и существующие английские адреса. Это не включённые сейчас маршруты и не выполненные редиректы.

| Существующий EN-адрес | Будущий RU-адрес |
| --- | --- |
| `/learn/olympiad` | `/ru/learn/olympiad` |
| `/courses/olymp-number-theory2` | `/ru/courses/olymp-number-theory2` |
| `/courses/olymp-number-theory2/topics/pilot_f2da4f4d6de9a3f01df74fffaacdbcf3792b3e29` | `/ru/courses/olymp-number-theory2/topics/pilot_f2da4f4d6de9a3f01df74fffaacdbcf3792b3e29` |

Глава сейчас выбирается параметром `?chapter=pilot_00601e92a4763b47e25e50821f251d9f573aa24b`. Этот параметр можно сохранить у русского адреса курса; это состояние выбора главы, не четвёртая самостоятельная индексируемая страница. В будущей реализации canonical остаётся адресом соответствующего курса.

У задач нет самостоятельного публичного маршрута `/tasks/:id`; не следует придумывать 20 новых `/ru/tasks/...`-страниц в рамках смены языка. Они остаются теми же Task/TaskVersion внутри русской версии темы и практики. Все 20 ID и версии сопоставлены будущему адресу темы в JSON-карте.

На старте **не предлагаются** `/ru/`-дубликаты главной, общего `/courses`, `/library`, поиска, пяти остальных направлений, Pure 1, Additional и Further Maths. Их русские подписи интерфейса не заменяют перевода учебного содержимого. Позднее отдельный русский каталог можно спроектировать по мере расширения контента; сейчас он не внедрён и не требуется для трёх пар выше.

При последующем внедрении:

- EN-адреса сохраняются; RU-адрес выбирает именно русские данные, без английского учебного fallback в пустых полях.
- Для курса нужно добавить краткое русское описание либо честно не выводить пустое поле. Сейчас оно пусто; в ходе аудита новый текст не сочинялся.
- `hreflang` и переключение EN/RU ставятся только между реальными языковыми парами; каждой версии нужен свой canonical. Это требования к будущей реализации, сейчас настройки не менялись.
- Закрытые кабинеты, аккаунт и инструменты преподавателя используют отдельное решение о языке профиля/cookie, без создания публичных `/ru/`-копий. Их индексация и серверный layout в этом аудите не изменялись.

## 5. Ограничения и отложенное

- Не внедрялись языковая маршрутизация, смена cookie/layout, hreflang, canonical, SSR каталогов, переработка главной, счётчиков или кабинетов. Никакие `/ru/`-страницы не опубликованы.

- Результат относится к локальной тестовой копии. Внешние сайты, Google Drive, Hostinger и production-база не обследовались в этой задаче.
- Категории `UNKNOWN`, тексты OCR, пустые критерии, языковая полнота интерфейса и независимая редактура содержания остаются отдельными задачами. Данных для начальной карты из трёх языковых пар достаточно; блокирующих вопросов владельцу нет.
