# Arena — отчёт об Этапе 4

Дата: 5 ноября 2026 года. Канонический проект: `D:\www\arena`.
Локальный просмотр: http://127.0.0.1:3102/ . Рабочая production-база не использовалась.

## 1. Что сделано и почему

Сначала создан локальный коммит **`11eb5a815ba87e724842485e7d8ce316e9ddfc90`**, `Document Russian content audit and proposed language URLs`. В нём ровно два документа: `docs/ARENA-LANGUAGE-AUDIT-20261105.md` и `docs/ARENA-LANGUAGE-URL-MAP-20261105.json`. Дорожная карта, исходники и артефакты в этот коммит не включены. После первоначальной проверки изменения Этапа 4 были оставлены без коммита. Этот отчёт дополнен после выполнения пунктов 1–2 раздела «Замечания по итогам проверки Этапа 4»; этап фиксируется отдельным локальным коммитом вместе с дорожной картой, без артефактов.

Выполнен Этап 4, включая замечания по итогам этапов 1–3 и все семь пунктов раздела владельца о странице курса.

- На главной шесть направлений без номеров 01–06; код экзамена — небольшая метка; у всех карточек одинаковое `Open course →`. Внутренние переходы не отмечаются стрелкой внешней ссылки.
- `/courses` отдаёт каталог в исходном серверном HTML. Группы следуют постоянному порядку IGCSE → Additional → AS & A Level → Further → School → Olympiad; показываются существующие группы. Неклассифицированный локальный демонстрационный курс сохранён в `Other courses`. Гостю не выводится нулевой личный прогресс. На карточках курсов сначала пять глав, далее `Show all`.
- `/library` называется `Practice`, типы приведены к обычному регистру. Первые 25 результатов приходят с сервера, при последующей загрузке используются силуэты карточек. Серверная выдача учитывает параметры фильтров. Поиск остаётся `noindex, follow`.
- Серверный рендеринг добавлен к существующему `Platform` и действующим API. Новый движок практики или отдельное приложение не создавались. Для двух значений HTML `lang` сделаны тонкие EN/RU-входы, использующие один серверный обработчик; прежний клиентский маршрутизатор остальных разделов сохранён.
- В публичных серверных layout и обработчике страниц нет чтения cookie языка или темы. Английский URL всегда отдаёт английский HTML, включая запросы с русской cookie. Тема устанавливается небольшим встроенным скриптом до отрисовки по клиентской cookie/localStorage. Проверено также с заблокированными скриптами Next.js, до гидратации.
- HTML публичных страниц сейчас **динамически рендерится сервером**, а не собирается в статические HTML-файлы. Анонимные данные каталога, первой страницы практики, тем и доступности переводов кэшируются на 60 секунд. Персональный прогресс не помещается в общий кэш. Публичный discovery использует повторное использование запроса в рамках рендера.
- Кабинеты, аккаунт и служебные инструменты получают `noindex, nofollow`. Их язык выбирается в меню аккаунта; используется язык профиля либо сохранённый клиентский выбор. Настройка кабинета не переводит английскую публичную страницу на русский.
- У реальных пар EN/RU есть самостоятельный canonical, взаимные `hreflang` и ссылки переключения. У английских страниц без перевода нет переключателя страницы и `hreflang`. Недоступные `/ru/`-адреса возвращают HTTP 404.

### Русский контент определяется базой

`publicLanguages()` читает актуальные версии русских конспектов/примеров и русские условия/подпункты доступных публичных задач, связанные с темами. Пустые локализованные поля, русские подписи интерфейса и OCR официальных критериев не считаются переводом учебного материала. Проверяются публикация, архивирование и ограничения доступа.

**В коде нет списка из трёх разрешённых адресов и нет импорта JSON аудита.** Новый русский учебный материал создаёт доступность соответствующих темы, курса и направления после истечения и обновления кэша, без добавления адреса в исходники. Это отдельно проверено на вымышленном новом курсе/теме в чистом модульном тесте, без записи в базу.

Текущий результат совпадает с аудитом: три пары:

1. `/learn/olympiad` ↔ `/ru/learn/olympiad`.
2. `/courses/olymp-number-theory2` ↔ `/ru/courses/olymp-number-theory2`.
3. `/courses/olymp-number-theory2/topics/pilot_f2da4f4d6de9a3f01df74fffaacdbcf3792b3e29` ↔ `/ru/courses/olymp-number-theory2/topics/pilot_f2da4f4d6de9a3f01df74fffaacdbcf3792b3e29`.

В русской выдаче нет подстановки английского конспекта/описания вместо отсутствующего русского. Пустое русское описание курса не создаёт абзац. Сохраняются русские материалы и 20 русских условий задач. `sitemap.xml`: **286 адресов, из них 3 русских**, с парными альтернативами; поиска и кабинетов в нём нет. Локальное тестовое окружение по-прежнему помечает публичные страницы `noindex, follow`; production здесь не разворачивался.

### Семь замечаний владельца о странице курса

1. Главы — ссылки с переносимым названием слева, приглушённым `N questions` справа и `aria-current` у выбранной. При ширине до 768 px вместо отдельного прокручиваемого окна — раскрытие `Chapter · Quadratics (1 of 10)`. Проверены смена главы, обновление страницы и сохранение адреса с параметром `chapter`.
2. `· Maths4U Original` убрано из отображаемых названий, служебная строка с UID — из условий, префикс источника — из конспектов. Данные и импортёр не переписывались. Метка происхождения показывается один раз в шапке соответствующего курса; на общей странице — в карточке курса. Наличие авторского материала определяется существующим `Source.name`, а не суффиксом названия главы. Полная классификация источников остаётся Этапу 6.
3. Счётчики глав подписаны `N questions`.
4. Типы практики — `Multiple choice`, `Short answer`, `Exam-style` для авторских глав, `Exam questions` для экзаменационных; для прочих письменных материалов сохранено `Written problems`. Ссылки оформлены единообразно.
5. У одного курса нейтральный подзаголовок: программа и количество вопросов. Внутреннее описание `Maths4U Original pilot: …` не выводится. Новые описания в базу не записаны; предложения приведены в разделе 5.
6. Гостевое уведомление оформлено нейтральной поверхностью, без зелёного состояния успеха.
7. Матрица проверяет переполнение текста внутри видимых элементов: `scrollWidth > clientWidth + 1`. Исключения ограничены формулами KaTeX с собственной горизонтальной прокруткой, намеренно прокручиваемыми навигационными полосами и явно оформленным многоточием. Общая ширина страницы проверяется отдельно, без этих исключений.

### Где обнаружены и исправлены служебные подписи

Исходный импортёр `src/lib/original-blocks.ts` и сохранённые тексты остались прежними. Найдены **10 названий глав**, **50 актуальных конспектов** (51 запись с исторической версией), **516 актуальных условий**: 100 заголовков с UID/баллами и 416 заголовков короткой практики. В одном описании курса находится внутренний текст пилота.

Очистка представления применяется в следующих местах:

- каталог курсов, карточки, списки и навигация глав, заголовок выбранной главы;
- страница темы, её заголовок, хлебные крошки и переходы между темами;
- названия в публичном поиске/discovery и метаданные соответствующих страниц;
- заголовки карточек задач и отображаемые условия, включая существующие просмотры задач/работ через `publicVersion()`;
- конспекты и примеры через проекции `topicContent()` и старое чтение `courses()`, включая данные учебной доски;
- названия курсов/глав в проекции сохранённого прогресса.

Очистка выполняется только в проекциях учебного контента. Общие `MathContent` и `Heading` не переписывают произвольный текст. Ответы учеников, названия их работ и исходные значения редактора не проходят эту очистку. `editableVersion()`, создание версий и импортёр сохранены. В проверке всех указанных актуальных условий и конспектов остаточных служебных заголовков — **0**; математический текст и баллы подпунктов сохраняются.

Также исправлены две мелочи из предыдущих замечаний: на главной повторение говорит о `skill/skills`, а в короткой практике оставлен один основной показатель `checked in this collection`. Редкое восстановление фокуса после проверки ответа перенесено на момент после обновления DOM; решение не перехватывает фокус, если пользователь уже перешёл в другое поле.

## 5. Что не сделано, ограничения и предложения владельцу

- Не начаты Этапы 5–8: новые кабинеты, «линза», полная классификация источников и очистка базы требуют отдельных этапов. Cambridge-вопросы не удалялись, не архивировались и не переименовывались.
- Не создавались переводы там, где их нет. Новые русские материалы должны быть действительно заполнены в актуальных учебных полях базы; доступность обновляется после обновления 60-секундного кэша. Русский список задач использует только задачи с русским условием/подпунктом.
- Публичные страницы — SSR с кэшем анонимных данных, не полностью статические HTML. Авторизованное персональное содержимое догружается по существующему API и не попадает в общий кэш. Переключение между EN/RU корневыми layout выполняет полную загрузку документа согласно правилам установленного Next.js.
- Во время массовых переходов/закрытия браузерных контекстов Next.js пишет `The destination stream closed early` с digest `328360726`. В установленном React это обработчик закрытия выходного RSC-потока; точная причина каждого сообщения не установлена. Не было HTTP 5xx или ошибок JavaScript в проверенной матрице, но это **не утверждение о чистом серверном журнале**. Сообщения не подавлялись, зависимости не исправлялись. До будущего deploy стоит отдельно проверить потоковые переходы на тестовом хостинге; проверка production в этот этап не входит.
- Проверки выполнены в headless Edge. Реальные телефоны, Safari, медленная сеть и полевые Core Web Vitals не проверялись. Автоматический поиск переполнения допускает только перечисленные узкие исключения; длинная формула может иметь собственную горизонтальную прокрутку.
- Сохранность всех таблиц подтверждена на существующем локальном снимке. Это не свежая сверка с production и не гарантия состава живой базы на текущую минуту.
- Описания одного курса в базу не сочинялись и не записывались. Возможные варианты **только для будущего решения владельца**:
  - Pure 1: `Study Pure Mathematics 1 through topic notes, worked examples and practice questions.`
  - Additional Mathematics: `Explore Additional Mathematics topics and choose questions for focused practice.`
  Сейчас оставлены нейтральные подзаголовки с программой и числом вопросов. Вопросов, блокирующих локальную проверку Этапа 4, нет.
