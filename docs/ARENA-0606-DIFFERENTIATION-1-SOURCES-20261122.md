# 0606 Calculus: Differentiation 1

## Sources and teaching sequence

- The official Cambridge 0606 programme, objectives 14.1–14.9, defines the derived function, power rules, product and quotient rules, tangents and normals, rates, small changes and extrema. The chapter introduces the gradient as a limiting idea. First-principles calculations and classification of inflexions are outside these objectives. [Cambridge 2025–2027 syllabus](https://www.cambridgeinternational.org/Images/662470-2025-2027-syllabus.pdf)
- Sue Pemberton's third-edition coursebook in `D:/new_books/addMaths10.pdf`, §§12.1–12.10, provides the sequence from derived function to optimisation. Each lesson in Arena uses its own explanations, models and values.
- Save My Exams illustrates the rule-to-application progression. Arena uses three method-focused sections per lesson, with a worked example and a check before increasing the number of decisions. [Introduction to Differentiation](https://www.savemyexams.com/igcse/further-maths/cie/additional-maths/25/revision-notes/calculus/differentiation/introduction-to-differentiation/), [Applications of Differentiation](https://www.savemyexams.com/igcse/further-maths/cie/additional-maths/25/revision-notes/calculus/differentiation/applications-of-differentiation/), [Modelling with Differentiation](https://www.savemyexams.com/igcse/further-maths/cie/additional-maths/25/revision-notes/calculus/differentiation/modelling-with-differentiation/)
- TLMaths provides alternate explanations using visual gradients and explicitly separated inner, outer or factor derivatives. Use only the methods named in the 0606 programme. [Gradients](https://www.tlmaths.com/home/a-level-maths/full-a-level/g-differentiation/g3-gradients), [Power rules](https://www.tlmaths.com/home/a-level-maths/full-a-level/g-differentiation/g2-differentiation), [Chain, product, quotient and related rates](https://www.tlmaths.com/home/a-level-maths/2nd-year-only/g-differentiation/g4-further-differentiation)
