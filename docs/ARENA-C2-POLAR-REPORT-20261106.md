## 3. Рисунки и формулы

В исходном JSON есть ссылки на SVG, но отсутствует каталог images/.
Нужные 64 модельных SVG найдены встроенными в учительском HTML владельца.
Проверены номер статьи, заголовок, alt/имя файла и положение внутри решения.
В задаче 5814 два рисунка, включая увеличенный участок; остальные имеют по одному.

Скрипт извлекает только модельные img, а не встроенные SVG формул.
Изображения преобразованы в 64 уникальных PNG с максимальной стороной 1600 px,
общий размер 4 027 273 байта. Хеши и имена воспроизводимы. Исходные SVG и
книга не копируются в публичный каталог. Все изображения просмотрены на четырёх
контактных листах; отдельно проверено решение в светлой и тёмной теме.

PNG подключены как неизменяемые SOLUTION-ресурсы TaskVersion. После открытия
решения работают ограниченные ссылки с разрешением; прямые ссылки на файл,
исходный JSON и физический путь изображения возвращают 404. Ссылка гостевой
сессии не открывается в сессии учителя. Сам учитель после публикации вправе
открыть решение и получить собственное разрешение.

Формулы отрисовываются KaTeX на сервере. Дроби и корни остаются математическими
формулами. Длинные неизменённые формулы владельца могут прокручиваться внутри
своего блока; горизонтальной прокрутки всей страницы нет.
