# 0580 Trigonometry teaching and source audit

Arena package `0580-trigonometry` covers Cambridge IGCSE Mathematics 0580 Section 6. The three Core lessons also serve Extended learners. Seven following lessons cover the additional Extended objectives. The content uses original diagrams, explanations, examples and practice data.

The programme checks were made against C6.1–C6.6 and E6.1–E6.6. The required exact values are sine and cosine at 0°, 30°, 45°, 60° and 90° and tangent at 0°, 30°, 45° and 60°. Graphs and trigonometric equations use 0°–360° inclusive. Written tasks include paper sketches of each of the three graphs, the ambiguous case of the sine rule and the angle between a line and a plane in 3D. The fractional and negative values in the equation lessons use degree mode and non-integer angles are given to one decimal place. [Cambridge 2025–2027 syllabus, pp. 27 and 51–52](https://www.cambridgeinternational.org/Images/662466-2025-2027-syllabus.pdf), [Cambridge 2028–2030 syllabus, Section 6](https://www.cambridgeinternational.org/Images/745681-2028-2030-syllabus.pdf)

The local Cambridge coursebook is Karen Morrison and Nick Hamshaw, *Cambridge IGCSE Mathematics Core and Extended*, 2nd edition, `D:/new_books/cambridge-igcse-mathematics-core-and-extended.pdf`. The local Oxford reference is David Rayner, Ian Bettison and Mathew Taylor, *Complete Mathematics for Cambridge IGCSE Extended*, 5th edition, `D:/new_books/pdfcoffee.com_complete-mathematics-for-cambridge-igcse-fifth-edition-extended-4-pdf-free.pdf`. The local Cambridge 0580/0980 Scheme of Work for examination from 2025, pp. 45–47, 51–52 and 55–56, places formula choice after right-angle recognition and uses sketches to connect the triangle, trigonometric curves and the 3D projection. Its distinct Extended activities determine where the learning route changes tier.

## Verification

The package includes 10 lessons with 60 worked examples, 60 Your turn checks and 62 extra practice checks. The native bank contains 50 short checks, 50 corresponding fresh checks and 200 written variants in 50 written families, with solutions and indicative Maths4U criteria. The 16 original SVGs show graphs and geometric diagrams. Calculation steps and fractions use KaTeX, while rules and exact values also have semantic HTML tables.

The independent audit recomputed 678 values and solution parts, including ambiguity, rounding, range endpoints and actual interior angles. It reconciled 828 written marks. Runtime fixture tests covered 222 answer fields with 570 accepted inputs and 387 rejections, including equivalent set notation, incomplete root sets and rounding boundaries. Each of the ten sheets printed as one A4 page. Checks use production renderer and print CSS in local fixtures. Runtime route and database checks follow registration on a test copy.
