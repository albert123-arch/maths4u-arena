Отдельно разобраны распространённые неточности:

- Область определения композиции учитывает обе исходные функции; сокращение
  дроби не восстанавливает запрещённый вход.
- Знак перед радикалом обратной квадратичной функции определяется исходной
  ветвью, а не знаком коэффициента при квадрате.
- Фактическая inverse domain может быть уже естественной области радикала.
- Утверждение «все общие точки функции и обратной лежат на y=x» требует
  дополнительных условий. Пример с `f(x)=6−x` показывает совпадающие графики
  и общие точки вне диагонали; для возрастающего случая дано обоснование.
- В комбинированных преобразованиях отслеживаются точка, порядок действий
  и принадлежность концов интервала, в том числе при отрицательном масштабе.
